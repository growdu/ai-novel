# 小说骨架

## 1. 故事类型
**成长 / 冒险 / 长篇升级流**（多地图递进，小人物逆袭）

## 2. 核心冲突
一个资质最底层、出身最卑微的人，想要攀上这个由天赋、出身、资源堆出来的金字塔顶端。阻挡他的是：先天的平庸、外界对"弱者"的轻视与碾压、以及越往上越要面对的庞然大物。

## 3. 人物骨架（无具体名字）

| 角色类型 | 描述 |
|---|---|
| **主角** | 天资最次、出身最贫的小人物。性格冷静、谨慎、算计、不冲动。信奉"命只有一条"，能跑就跑，绝不硬拼。 |
| **女主 / 爱人** | 实力远高于主角的异性强者，关系起初不对等，曾有名分上的牵连（被迫/契约），后逐渐并肩。 |
| **早期师傅（A）** | 收主角入门、给主角最初功法的人。但此人目的不纯，把主角当工具。 |
| **早期师傅（B）** | 真正愿意教主角的人，能力有限，最终为护主角而死（或付出极大代价）。 |
| **兄弟 / 儿时伙伴** | 和主角一起长大的同龄人，资质比主角略好但也没多好。代表主角"过去的自己"和"另一种人生可能"。 |
| **反复出现的对手** | 与主角同辈、起步相近，但走的是另一条路（狠辣/张扬/有靠山），形成长期对照。 |
| **地图大反派** | 每个阶段都会出现一个压制主角的强者，主角前期完全打不过，只能隐忍、布局、寻找突破口。 |
| **神秘/远古强者** | 与主角核心金手指有关的上古存在，可能敌可能友，构成终极悬念。 |

## 4. 主要事件链

1. **出身与触发**：主角出身最底层，命运中出现一个微小但关键的契机（金手指/宝物/奇遇），开启修行之路。
2. **入门与被骗**：进入一个小型组织，遇到表面是师傅实际是利用他的人。主角从一开始就觉得不对，但必须依靠对方活下去。
3. **遇到真师傅**：另一个真心教他、但能力有限的人出现，给予主角最初的立身之本。
4. **兄弟离散**：儿时伙伴分道扬镳——有人留下来，有人去闯，有人死。这场分离是主角第一次真正"成人"。
5. **第一地图大危机**：所在组织遭遇外来强敌碾压，主角被迫逃亡 / 背井离乡。
6. **在第二地图立足**：以新身份进入一个更大的世界，从最底层开始，靠金手指和谨慎慢慢积累家底。
7. **情感线的建立与错过**：与高阶女修产生纠葛，关系因身份差距和外部压力而复杂，常有被迫分离。
8. **第二地图大危机**：被卷进两个大势力之间的冲突，被迫选边 / 逃亡 / 借势。
9. **崛起与暴露**：金手指的秘密开始被强者察觉，主角成为被追猎的对象。
10. **跨地图跃迁**：突破当前世界的极限，进入更高一层的世界（飞升 / 跨界 / 通道）。
11. **更高世界的重新洗牌**：到了上面发现自己还是底层，又要重新积累，但有了前几层攒下的底子。
12. **终极阴谋浮现**：远古强者 / 跨地图的大反派浮出水面，与主角金手指的来历直接相关。
13. **最终对决**：主角集合几层地图积累的人脉、资源、修为，对抗最终对手。
14. **结局**：主角成道，但代价是身边人大多散去，留下的是一个已经"不像人"的自己。

## 5. 高潮

- **高潮一**：在第一地图或第二地图，主角被逼入绝境，身边的人接连死去，迫使他从"跑"变成"打"，完成心态与实力的双重跃迁。
- **高潮二（终极）**：与远古大敌的最终对决，不再是个人恩怨，而是关乎整个世界存亡的博弈。

## 6. 主题

**一个普通人如何用"不普通"的方式活下来。**

表面是升级打怪，内核讲的是：在天赋决定一切的世界里，平庸不是耻辱，谨慎不是怯懦，慢就是快，活着本身就是胜利。最终主角成仙，但他失去的比得到的多——这是这个故事最冷的一层。

## 3. 改编后设定

### 3.1 世界观

**核心设定：灵气复苏的现代修仙界**

- **时间起点**：公元 2024 年，"灵气复苏元年"。全球多地出现灵气潮涌，古老洞府、遗迹、秘境陆续在现实中显现。
- **修行体系**（与源小说对齐）：
  - 等级：练气 → 筑基 → 金丹 → 元婴 → 化神 → 渡劫 → 仙人（飞升上界）
  - 灵根：单灵根 / 双灵根 / 三灵根 / 五灵根 / 天灵根 / 变异灵根
  - 资源：灵石、丹药（下品至仙品）、功法、飞剑法宝、储物袋（容量受限）
  - 渡劫：受天雷会伤，重则身死道消；不是过场戏
- **现代社会的硬约束**：
  - 修行并非无法无天。政府设"灵管局"统一管理，修士需登记。
  - 灵石与人民币双轨制，民间仍以法币流通，大额交易用灵石结算。
  - 飞剑在禁飞区会被灵管局雷达锁定；高铁、飞机仍是长途主力。
  - 功法、丹药受知识产权法、灵药管理局双重监管。
- **势力格局**：
  - 官方：灵管局 + 国家修行学院体系
  - 隐世宗门：昆仑、蜀山、龙虎山等传统大派浮出
  - 修行家族：南北世家、五大古族
  - 新兴资本：科技修行公司、丹药财阀
  - 散修：底层人最多，资源最少
- **地图结构（5 张地图，对应源小说 6 张）**：
  1. **青阳县**（对应七玄门）：地方小城，灵气稀薄
  2. **江南省**（对应越国）：灵气浓郁，势力林立
  3. **东海乱域**（对应乱星海）：跨国势力交汇的混乱海岛与秘境
  4. **昆仑上域**（对应灵界）：与异界接壤的高阶世界
  5. **飞升上界**（对应仙界）：渡劫之后

### 3.3 主线剧情（按地图重写）

**地图一 · 青阳县（第 1-80 章）**
灵气复苏第二年，沈拙在青阳县福利院长大。一场山洪让他在深山老林里捡到一只破旧青铜小瓶（拙瓶），瓶中残液能让一株濒死的百年灵芝几日内长成。沈拙凭此发现自己的三灵根也能修行，咬牙加入清河武馆。馆主严朴表面和善，实则早盯上拙瓶。同期孤儿卫虎也入门，两人结为兄弟。武馆老教习孙守一看出沈拙资质虽差但心性极佳，私下传他基础功法。半年后外来邪修"血手屠夫"韩重压境，孙守一为护沈拙被擒，沈拙当夜携拙瓶逃亡。卫虎选择留在青阳守师傅墓——"哥你跑，我守家。"两兄弟自此分道扬镳。

**地图二 · 江南省（第 81-200 章）**
沈拙以"散修沈三"的新身份混入江南省，用拙瓶在郊外租地种灵药倒卖，缓慢积累资源。一次灵药交易中，他误闯苏家秘境，被苏家金丹女修苏清宁当场擒下。两人因秘境中"上古契约"产生名分纠葛（苏清宁修为被契约反噬，需沈拙这个三灵根修士做"药引"才能解），被迫绑定。同期陆家少爷陆骁看中苏清宁，屡次挑衅沈拙。沈拙反复隐忍、设局、借势，将陆骁数次精心策划的"踩人"现场反转为"打脸"现场。江南省世家大战爆发，周家老祖碾压一切，沈拙卷入金丹对轰的余波，被迫带苏清宁逃出江南。

**地图三 · 东海乱域（第 201-300 章）**
沈拙抵达东海乱域——一片由海上岛屿、跨国秘境、邪修据点组成的灰色地带。各国势力在此角力，无灵管局管辖，是真正的"乱星海"。沈拙以种药、炼丹、倒卖情报为生，组建了一个小而精的班底（3-5 名忠心的筑基期打手）。拙瓶的秘密开始被黑潮盟主察觉，沈拙成为被追猎的目标。逃亡途中他与苏清宁重逢，两人在一座孤岛上共度半年，关系从"契约绑定"真正转为"互相托付"。沈拙突破金丹，借助乱域的混沌资源一举跃迁至元婴门槛。黑潮盟主追杀至绝境，沈拙反杀，借乱域中的远古传送阵逃往昆仑。

**地图四 · 昆仑上域（第 301-380 章）**
昆仑是灵气复苏后开启的"高阶世界入口"，内里是与现实平行的另一层空间，时间流速不同。元婴期在人间已是顶尖，在昆仑只是中下层。沈拙以"外来野修"身份重新从底层爬起，发现昆仑中修士动辄数千年寿命，动辄化神级大佬。他在这里第一次接触到"无名上人"留下的远古遗迹，逐步揭开拙瓶的来历——它与一场跨越数个纪元的"天人大战"有关。昆仑异族大能（域外天魔首领）觉醒，要将整层世界吞噬炼化。沈拙集合人间积累的人脉、昆仑新交的朋友、远古遗迹的宝物，与异族大能展开跨越数年的拉锯战。

**地图五 · 飞升上界（终局，第 381-400 章）**
沈拙渡劫成功，飞升上界。但上界并非乐土——无名上人的残魂在上界现出真身，揭示终极阴谋：他需要沈拙这个"拙瓶传人"做他重生的容器。曾经的"金手指"原来是远古大能的复生工具。沈拙集合五张地图的所有积累——人脉、资源、修为、心性——与无名上人展开最终对决。代价极大：孙守一早逝、卫虎在昆仑一战中重伤远遁、苏清宁为护他被无名上人重创本源。最终沈拙以"凡人之心"胜出，斩断拙瓶与无名上人的联系，将远古大能彻底封印。结局：沈拙独自站在上界之巅，身边无人。留下的是一个已经"不像人"的自己，和一只再无灵光的拙瓶。

## 5. 改编要点

### 5.1 关键还原点（必须保留）

1. **核心人设不变**：沈拙的"谨慎、算计、永远先想退路"是整本书的灵魂。**不能为了爽文节奏让沈拙变莽**。所有"打脸"都是被迫应战，不是主动挑衅。
2. **金手指的本质保留**：拙瓶是远古大能复生工具，**这个伏笔从地图一就要埋**，每次沈拙用瓶时给一个微小的不安感。终局揭露时读者回头看才恍然大悟。
3. **师傅 A 的早暴露**：严朴的伪善不能藏太久，地图一就需让沈拙察觉，并保留"先借他立足再翻脸"的算计过程。
4. **师傅 B 的必死**：孙守一之死是沈拙"成人"的关键节点。死法不能窝囊——必须是为护沈拙而死，让沈拙从此背上"第一条人命债"。
5. **兄弟离散**：卫虎留、沈拙走，是第一次真正意义上的分道。这一幕要给足分量，写出"两个人都没错，但路就是不一样"的撕裂感。
6. **女修的"先强后并肩"**：苏清宁的实力必须长期碾压沈拙，绝不能"男主一升级就反超女主"。女主的强是独立的，不依附男主。
7. **终极代价**：成道但身边人散去。卫虎重伤远遁、苏清宁本源受创、孙守一早逝——沈拙最后是"赢了，但空了"。这是源小说最冷的一层，**爽文也不能稀释它**。
8. **多地图递进**：5 张地图，每张地图沈拙都是"小人物"，只是"上一张地图的小人物比这一张的小人物强一点"。

### 5.2 可以自由发挥（壳的细节）

1. **现代元素的具体用法**：手机、监控、银行账户、灵管局备案、高铁禁飞区雷达——这些怎么和飞剑、储物袋、灵识传音共存，由作者自由填充。可以有"用支付宝收灵石"的黑色幽默，但不要喧宾夺主。
2. **爽文打脸的具体桥段**：陆骁每次怎么挑衅、沈拙怎么反杀、围观群众怎么震惊——这部分可以写得密、写得爽、写得夸张。这是"换壳"释放的最大空间。
3. **班底角色**：沈拙在东海乱域的 3-5 名班底可以原创，不需要严格对应源小说配角。让配角有自己的目的、自己的生活，不要都是"主角的工具人"。
4. **女配暧昧线**（如要加）：源小说没有，可以根据爽文节奏加 1-2 个女配暧昧点缀，但**不能影响沈拙-苏清宁主线**。建议点到为止，避免稀释核心情感。
5. **战斗细节**：法术怎么放、飞剑怎么打、阵法怎么布——可以写得比源小说更"网文化"，比如"沈拙一指点出，筑基老修当场吐血倒退"，但不能脱离源小说的硬规则（阵法要提前布、储物袋有容量、渡劫有物理代价）。
6. **地图大反派的最终死法**：每个地图大反派怎么死，可以有不同设计——有的被沈拙亲手斩杀，有的被借势搞死，有的自爆，有的被更强者顺手灭了。让沈拙的"谨慎"在反派死法上也有所体现：他从不亲自冒不必要的险。

### 5.3 爽文化处理的红线（不能越）

1. **不能让沈拙变天才**。他永远是三灵根，只是金手指 + 心性 + 时间累积让他追上。
2. **不能"境界碾压一切"**。再高的境界也有解决不了的事——情报、阵法、人心、时机、代价。
3. **反派不能只是"坏的"**。每个反派要有自己的逻辑和身不由己。血手屠夫有他的江湖无奈，陆骁有家族压力，周家老祖有自己的执念。
4. **女主不能是花瓶**。苏清宁的强是真实的，金丹期就是能压沈拙。后期沈拙接近她，是靠"心性 + 金手指 + 谨慎"三件套，不是开挂。
5. **不能稀释"凡人感"**。每 30 章至少一个"沈拙数灵石、算账、担心下个月房租"的凡人场景。这是本书区别于其他升级流的核心。
