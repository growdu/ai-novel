# 源小说骨架

# 骨架提取

## 1. 故事类型
**暗黑群像 / 长线悬疑 + 成长悲剧（双人叙事）**

## 2. 核心冲突
两个童年受害者在彼此的"纽带"下走向彻底分化：一方沉入暗处，用一切手段为另一方扫清上升道路上的所有障碍；另一方则在阳光下不断攀升，却绝不能回头确认那道影子。阻挡他们的不是单一敌人，而是**这段关系本身——它建立在不可告人的秘密之上，任何一方被看见，都意味着双方毁灭**。同时，一个跨越二十年的执拗追查者始终差一步逼近真相。

## 3. 人物骨架
1. **男孩（暗）**：童年目击 / 卷入长辈罪行后，被迫（或主动）成为施害者逻辑的继承者。在社会中无身份、无光亮，活着的全部意义是为女孩服务。
2. **女孩（光）**：童年的另一受害者，成年后成为"完美精英女性"。她的每一次升迁背后都有男孩制造的死亡。
3. **追查者（警察）**：中年起步，跟了这个案子二十多年，靠直觉和执念活着，错过关键节点数次，最终在退休 / 失势之际拼出全貌。
4. **男孩的父亲**：原始加害者，触发一切事件的起点。死于故事前期。
5. **女孩的母亲**：依附于男孩父亲，道德破产。是女孩少年时期最重要的伤害源之一，后被边缘化 / 消失。
6. **女孩的养母 / 姨母式人物**：体面、自律、女性气质的庇护者，把女孩从原生家庭拉出来，给了她"在阳光下重新做人"的外壳。
7. **男孩的童年挚友 / 搭档**：唯一接近男孩真实身份的人，最终因知道太多而被男孩亲手处理。
8. **被清除者 A（女孩的追求者 / 生意伙伴）**：挡了女孩上升路，被男孩设局杀死。
9. **被清除者 B（更接近真相的调查者 / 知情者）**：危险到可能牵连女孩，必须消失。
10. **时代背景群像**：80 年代泡沫经济、90 年代衰退、00 年代信息化——社会变迁作为两人罪行得以藏匿的掩护层。

## 4. 主要事件链
1. **童年交汇**：男孩和女孩因父辈关系相遇，生活轨迹短暂重叠。
2. **目击 / 触发事件**：男孩在某个封闭空间（仓库 / 废弃建筑 / 旧宅）撞见父辈对女孩施害（或伤害其至亲）。女孩已先在场。
3. **第一桩死亡**：男孩当场或事后杀死自己的父亲。女孩目睹或默许。两人从此结成无形的契约。
4. **分道**：男孩脱离原生家庭，进入无光社会；女孩被体面亲属收养，进入上升轨道。
5. **少年期第一波操作**：男孩为女孩清除某个能把她拉回过去的具体威胁（母亲 / 知情邻居 / 旧日证人）。
6. **女孩的第一次"漂亮翻身"**：升学 / 转学 / 嫁入 / 创业，凭借被洗白的新身份。
7. **男孩建立地下网络**：开小店 / 黑产 / 信息中介，作为长期作案的资金和身份掩护。
8. **女孩进入成人世界**：恋爱 / 婚姻 / 事业，每一段关系中都有男孩在暗中观察和干预。
9. **第二波清除**：女孩的某个追求者、合伙人、或前情人开始对她构成麻烦或威胁，男孩动手制造其"意外"。
10. **追查者初露端倪**：当年的案件被重新调出，老警察第一次逼近真相，证人死亡 / 关键人证失踪。
11. **女孩的继续攀升**：外表愈发光鲜，身边的男性不断"消失"。
12. **男孩的牺牲链条扩大**：为保护女孩的伪装，男孩牺牲掉自己最亲近的同伴（童年唯一朋友）。
13. **追查者拼出全貌**：通过多年积累的细节（不在场证明的漏洞、死者之间的隐藏关联、某个童年未被发现的目击者），追查者终于把两条线并到一起。
14. **收网**：追查者找到男孩，男孩拒捕 / 自杀 / 在最后关头选择坠楼身亡。
15. **擦肩而过**：女孩路过事发现场。两人之间没有任何语言 / 眼神的交换。女孩背影消失在人群中。

## 5. 高潮
- **次高潮**：追查者首次把"女孩身边连续死亡"和"男孩的地下身份"对接起来。
- **真正高潮**：男孩在追查者面前以坠楼（或类似方式）身亡——他**主动选择死亡**，既是封口，也是对女孩最后一次保护（他死了，女孩身上的线索就断了）。随后女孩**面无表情地从现场走过**，读者才最终确认：这二十年的全部罪行，她不仅知情，而且是一切的源头。

## 6. 主题
**两个被同一桩童年罪行塑造的人，永远无法并肩走在阳光下——她越亮，他就必须越暗；他越暗，她就越是被钉死在那个必须继续亮下去的位置。** 故事真正讲的不是"谁杀了谁"，而是**依附共生中爱与罪的不可分割**：救赎从未存在过，所谓保护本身就是一种长期的、以对方为牢笼的囚禁。

# 改编方案

# 1. 源小说骨架

**类型**：暗黑群像 / 长线悬疑 + 成长悲剧（双人明暗叙事）。
**核心冲突**：两名童年受害者在同一桩不可告人的秘密下结成终生契约——男孩沉入暗处为女孩扫清所有上升障碍，女孩在阳光下不断攀升却永不能回头确认那道影子。阻挡他们的不是单一敌人，而是这段关系本身。
**关键人物**：男孩（暗处施害者）、女孩（光处上升者）、执拗追查者（中年起步、二十年拼图）、男孩父亲（原始加害者）、女孩母亲（依附者）、女孩养母（体面庇护者）、男孩童年挚友（最终被牺牲）。
**事件链**：童年交汇 → 封闭空间触发 → 男孩杀父 → 分道（一个入暗一个上升） → 少年期清除 → 女孩翻身 → 男孩建地下网络 → 成人世界第二波清除 → 追查者逼近 → 擦肩而过（男孩坠楼、女孩无表情走过）。
**真正高潮**：男孩主动跳楼封口，追查者与读者才意识到——这二十年的全部罪行她不仅知情，而且是一切的源头。
**主题**：依附共生中爱与罪的不可分割。救赎从未存在。

# 2. 改编方向

**双线操作：换名 + 换壳（校园题材全年龄段承载）**

- 保留：双主角一升一沉结构、约二十年时间跨度、童年原始创伤 + 男孩杀父、男孩地下网络、女孩身边男性连续"消失"、二十年追查者、男孩最终主动坠楼、擦肩而过无交流的结尾。
- 改换：所有人物名、所有场景（仓库→校园封闭空间、卖身/卖信息→校园黑产、婚姻生意场→大学与初入职场的攀爬）、所有死法（须符合校园工具边界：坠落 / 触电 / 溺水 / 中毒 / 窒息 / 制造意外）、时代背景（1980s-2000s日本泡沫 → 2003-2025中国非典到疫情后）。
- 题材硬规则：每段故事必须落在某个学段（小学/初中/高中/大学/职场初年），校园场景是时代切片而非全部卷宗。

# 3. 改编后设定

## 3.1 世界观

**时间**：2003-2025。非典、奥运、智能手机普及、高考改革、双创、疫情、ChatGPT——这些是男孩罪行得以藏匿的时代掩护层。
**地理**：虚构南方城市**南屿**为主舞台，后期切至**北京**。
**学段切分**：

| 时段 | 学段/身份 | 锚点地点 |
|------|-----------|----------|
| 2003-2009 | 建新小学（城乡接合部公立小学） | 南屿市郊接合部 |
| 2009-2012 | 南屿第十二中学（普通公立初中） | 城中村附近 |
| 2012-2015 | 南屿外国语学校（私立名校） | 市中心 |
| 2015-2019 | 翰林大学（虚构 985） | 北京 |
| 2019-2025 | 职场初年（投行/互联网） | 北京/上海 |

**校园题材的载体**：每个学段都是两人关系演化的容器，不是单纯的恋爱+考试。
- 小学：原始创伤发生的场所。
- 中学：分道后的第一次"清扫"现场。
- 高中：女孩第一次漂亮翻身的舞台。
- 大学：第二波清除的主场域。
- 职场初年：最终收网的舞台。

## 3.2 人物

1. **程辞 / 沈渡**（男孩，暗）—— 建新小学五年级学生。目睹父亲在封闭空间对方茹施暴致死，杀父后失踪。成年后以"沈渡"为名，在大学城附近经营**二手电子回收 + 校园贷中介**作为地下身份与资金来源。无学历、无姓名（多次更换身份证）、无光亮，全部意义在于为江鸢服务。**核心特征**：极度的冷静、过早的成人化、对一切温情本能地逃避、对江鸢的每一次靠近都意味着在他已经离婚之后的进一步自我销毁。**

2. **江鸢**（女孩，光）—— 建新小学同班同学。被姨母唐映雪收养后改姓"江"，进入全新生活轨迹。翰林大学商学院毕业后入职一线基金。外表是完美的精英女性——自律、漂亮、聪明、滴水不漏。**核心特征**：从不回头、从不提过去、所有温情都以"我不知道"为盾牌、身边男性"消失"的速度和她上升的速度完全同步。**

3. **韩牧**（追查者）—— 当年负责建新小学周边命案的年轻刑警，错过关键节点数次。2015 年退休，在大学城附近开了一家旧书店"牧之书局"。二十年来用业余时间追这个旧案，靠直觉与执念活着。**核心特征**：人老了但脑子不糊涂、不接受任何"意外死亡"的巧合、能在二十年前的旧报纸和新一代的社交动态之间看出接缝。**

5. **程远达**（男孩父亲，原始加害者）—— 程辞父亲，南屿市郊接合部的个体户（开小卖部 + 跑运输）。与方茹有长期的权钱/情感纠缠。死于故事开场数年之内。**核心特征**：粗俗、精明、对儿子程辞不冷不热、对方茹有绝对控制权。**

6. **方茹**（女孩母亲，依附者）—— 江鸢生母，南屿城中村的小学代课教师。依附于程远达，是其暴力行为的承受者与掩盖者。死于故事开场。**核心特征**：柔弱、自欺、把女儿当作自己最后的筹码。**

7. **唐映雪**（女孩养母，体面庇护者）—— 江鸢姨母，南屿市某三甲医院呼吸科主任（非典一线医生出身，后任副院长）。把江鸢从原生家庭拉出，给了她"重新做人"的外壳与路径。**核心特征**：体面到极致的女性、有自己的边界与极寒的慈爱、不允许江鸢提过去一个字。**

9. **许诺**（男孩童年挚友 / 最终被牺牲者）—— 建新小学五年级同班，是程辞当年唯一接近其真实身份的人。成年后成为程辞地下网络的核心搭档（运营二手电子回收的资金端）。最终因为知道太多，在故事后期被程辞亲手处理——这既是程辞对江鸢的最后一次保护，也是他早已不是人的证据。**核心特征**：聪明、讲义气、本可走正道、被程辞绑死。**

10. **陈屿**（女孩大学追求者 / 被清除者 A）—— 翰林大学经济学院研究生，江鸢大学时期的男友/合伙人。聪明、有野心、开始接近江鸢的真实过去。**核心特征**：本可与江鸢"登对"，但他的好奇心是定时炸弹。**

12. **周晓棠**（被清除者 B）—— 当年建新小学的代课教师，方茹的同事，目睹过程远达与方茹关系的某些片段。多年后成为某教育机构负责人，在社交媒体开始活跃。**核心特征**：知道得不多但足够危险，且她开始公开回忆"那段往事"。**

**配角群**（不作为核心出场但功能必要）：
- 江鸢大学室友 / 某位女同学（用作她"光鲜表面"的镜子）
- 程辞某次"业务"的客户（用作地下网络的活体证据）
- 韩牧当年的同事 / 现警方某负责人（用作追查者的对手与帮手）

# 4. 分章大纲

**总规模**：35 章，约 10-11 万字。每章 3000-3500 字。
**分卷**：4 卷，每卷对应一个学段/人生阶段。

## 第一卷《锅炉房》（2003-2009，建新小学，6 章）

> 主题：原始罪行的发生。短、冷、不解释。

1. **建新小学**——程辞和江鸢的日常：城乡接合部小学的一天。两个十岁出头的孩子，分别来自两个不正常的家庭。场景用午饭、家访、放学校门口三个切片建立。
2. **程远达**——男孩父亲的截面：开小卖部、跑运输的男人，掌控方茹、对自己、家庭成局。程辞在这个家庭里的位置极低。江鸢偶尔出现在程远达的某些接送场合。
3. **方茹**——女孩母亲的截面：代课教师、城中村里的女人、被程远达长期控制与经济压榨。江鸢是她唯一的筹码，也是她试图逃离的唯一阻碍。
5. **废弃锅炉房**——那一夜：放学后江鸢被程远达带去学校锅炉房（家长帮工的借口）；程辞跟踪；方茹被程远达殴打致死（或重伤）。程辞当场用现场物（铁管 / 砖头 / 美工刀）杀死父亲。方茹的死被伪装成意外。
6. **分道**——处理现场后两个孩子各自回家又各自消失。程辞第二天被远房亲戚接走；江鸢一周后被姨母唐映雪从南屿接走。程辞在火车站见过江鸢一面，江鸢没有看他。
7. **第一道擦痕**——三年后（2006）。程辞已经在某亲戚家无法忍受、开始在城中村边缘游荡。一个知道方茹死因细节的房东在他准备给未来酒店"多嘴"之前被他用某种方式阻止。**少年期第一次操作。**

# 5. 改编要点

## 必须保留（核心戏剧张力）

1. **童年原始创伤必须发生在封闭空间**——废弃锅炉房 / 旧教学楼 / 学校某个死角。这是整部作品的第一块基石。
2. **男孩当场或事后杀死自己的父亲**——这是两人"无形契约"的物理起源。不能改。
3. **女孩目睹或默许**——她不能不在场。这决定了她之后所有"光鲜"都是建立在共同犯下的秘密之上。
4. **22 年时间跨度**——两人关系的演化必须有时间感，不能压缩。
5. **男孩的地下网络**——必须有资金端、有身份掩护、有客户。这是他能长期活着、并能为江鸢做事的物理基础。
6. **女孩身边男性连续"消失"**——她每一次上升都对应着一次"意外"。这些意外在追查者眼里最终连成线。
7. **跨越多年的追查者**——中年起步、错过关键节点数次、最终在退休/失势之际拼出全貌。
8. **男孩最终主动选择死亡**——既封口，也是对女孩最后一次保护（他死了，线索就断了）。
9. **擦肩而过无交流的收尾**——女孩面无表情从现场走过。这才是故事真正的结局。
10. **男孩牺牲自己最亲近的同伴**——许诺。这是程辞早已不是人的证据。

## 可以自由发挥（外壳可换）

- **死法设计**（须符合校园题材工具边界）：
  - 美工刀 / 铁管 / 重物（小学阶段，可行）
  - 校园贷逼债伪装跳楼 / 自缢（中学阶段）
  - 溺水 / 触电 / 煤气 / 车祸 / 坠落伪装成意外（大学阶段）
  - 高坠（最终）

- **男孩地下网络的具体形态**（结合校园时代）：
  - 小学-初中：边缘游荡、城中村跑腿
  - 高中-大学：二手电子回收 + 校园贷中介 + 信息中介
  - 职场初年：黑产 / 洗钱 / 非法催收

- **女孩的专业与职业**：
  - 大学：商学院 / 经济 / 法律
  - 职业：投行 / 基金 / 律师 / 互联网战略

- **追查者的具体身份**：
  - 当年负责建新小学周边命案的刑警
  - 退休后在翰林大学东门外开旧书店"牧之书局"
  - 受邀给某门课做客座讲师的犯罪学背景可作为合理性铺垫

- **时代背景锚点**（作为男孩罪行得以藏匿的掩护层）：
  - 2003 非典（唐映雪一线医生的合理性）
  - 2008 奥运（南屿外国语学校的赞助）
  - 2012 移动互联网（校园贷兴起）
  - 2015 双创（陈屿的"创业失败"合理性）
  - 2018 P2P 暴雷（地下资金端的合理性）
  - 2020 疫情（周晓棠的线上活动合理性）
  - 2023 大模型兴起（最终清扫时间窗）

## 题材硬规则自检

- [ ] 校园环境符合各年龄段（小学生不像大学生那么机警，中学生不像高中生那么圆滑）
- [ ] 师生关系有边界（唐映雪 / 退休老师 / 韩牧客座讲师）
- [ ] 不让老师"全知全能"——他们也是普通人，也被男孩算计
- [ ] 不只是"恋爱+学习"——展现成长、展现代价、展现两人差距越拉越大
- [ ] 校园场景是两人关系演化的容器，不是全部卷宗

## 文风自检

- [ ] 短句为主，删掉所有形容词
- [ ] 不解释，只呈现
- [ ] 节奏冷，留白大，不为了冷而冷
- [ ] 不出现原作中"她眼眸中闪过一丝复杂神色""他似乎陷入了沉思""空气中弥漫着……的气息"等 AI 腔
- [ ] 动作先于心理——用江鸢的某个具体动作（剪指甲 / 整理衣柜 / 接电话时的停顿）来表达她的内心，而不是直接说"她感到复杂"
- [ ] 对话是人话——会打断、会重复、会说半句、会跑题
- [ ] 主角可以笨、可以有偏见、可以说错话（程辞的某些判断可以出错；江鸢的某些"完美"可以有裂缝）
- [ ] 配角不必都是主角的镜子（许诺有自己的目的、唐映雪有自己的边界、韩牧有自己的执念）
- [ ] 不出现"总结全文式"内心独白
- [ ] 不混用第三人称限制视角与第一人称（默认贴着程辞；某些关键节点切到江鸢视角；韩牧作为外部观察者）
