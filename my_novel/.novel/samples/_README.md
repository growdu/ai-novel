# samples/ 目录说明
这个目录用于存放作者手写的高质量片段，用于让模型深度模仿你的语感。

使用方式：
1. 在这个目录里放一个或多个 .md 文件，每个文件放一段你希望模型模仿的文风片段（200-1500 字最佳）。
2. 文件名随意，但建议用数字序号（如 01.md, 02.md）让排序可预测。
3. 模型会在写每章时自动从这个目录随机抽 1-2 段作为风格参考。

注意：
- samples 里不要放你想要"用"的内容——它只影响风格，不影响情节。
- 同一项目里 samples 一旦存在就会自动启用；要关闭时把文件移到子目录里或者改名（如 .bk ）即可。
示例：
my_novel/.novel/samples/
├── 01.md   # 你喜欢的某段短句白描
├── 02.md   # 你喜欢的某段对话密度
└── _README.md
