# 网文爽感文风

本文件是面向网络小说市场的文风预设。
核心：节奏快、爽点密、读者欲罢不能。

# 经典爽文
## 语言特征
- 短句为主，节奏飞快
- 对话占比 50% 以上
- 反派必须"嘴贱 + 脸欠"——让读者想看主角打脸
- 打脸场景要"铺垫 -> 亮出 -> 震惊 -> 求饶"四步走
- 升级感明确：每章主角必须变强一点点
## 节奏
- 每 1000 字一个小爽点
- 每 3000 字一个中爽点（打脸 / 获得）
- 每章结尾留钩子
## 写作时注意
- 不要"反派太蠢"——要有智商
- 不要"主角太顺"——要有挫折
- 不要"洗白反派"——反派的坏要彻底
## 作家参考
- 辰东（遮天 / 完美世界）
- 我吃西红柿（莽荒纪 / 盘龙）
- 天蚕土豆（斗破苍穹 / 武动乾坤）

# 轻松爽文 / 沙雕
## 语言特征
- 段子化语言
- 反差萌：严肃场景 + 沙雕言行
- 反派也是搞笑的
## 节奏
- 极快，每段都有笑点
- 不沉重、不虐
## 写作时注意
- 不要"强行搞笑"——角色要自然
- 不要"低俗"——沙雕不等于低俗
## 作家参考
- 会说话的肘子（大王饶命）
- 老鹰吃小鸡（全球高武）

# 黑暗流 / 杀伐果断
## 语言特征
- 短句、利落
- 主角不废话
- 反派必须死——不洗白
## 节奏
- 紧张、密集
- 反派登场 -> 反派被打 -> 反派死
## 写作时注意
- 不要"为了杀而杀"——要有理由
- 不要"主角太冷血"——要有底线
## 作家参考
- 梦入神机（永生 / 龙蛇演义）
- 烽火戏诸侯（雪中悍刀行 / 剑来）

# 智商流 / 智斗
## 语言特征
- 心理描写多
- 主角要"看出对手的破绽"
- 反派也要聪明
## 节奏
- 张弛有度
- 每一招都要有来有回
## 写作时注意
- 不要"主角全知"——要给对手一些空间
- 不要"反派太蠢"——要真的难对付

# 软文 / 慢热 / 沉浸
## 语言特征
- 多感官描写
- 节奏慢
- 重氛围
## 写作时注意
- 不要"太慢"——读者会弃坑
- 不要"没有爽点"——可以慢但要有

# 搞笑吐槽 / 反迪化
## 语言特征
- 元叙事
- 主角"吐槽"其他网文套路
- 读者会心一笑
## 写作时注意
- 不要"嘲讽观众"——作者 vs 读者是合作

# 后宫 / 甜宠（男频 / 女频）
## 男频后宫
- 多个女性角色各有特色
- 不"脚踏多船"——感情线清晰
## 女频甜宠
- 男女主对手戏
- 甜蜜但有冲突

# 经典怀旧 / 重生
## 特征
- 利用"知识差"
- 怀旧感（年代背景）
- 把握历史节点

# 仿写特定网文风格
作者可以指定"模仿 XX 的风格"——
novel style --style 仿斗破苍穹风格
或 novel adapt --source 凡人修仙传 --style 仿凡人修仙传风格

# 通用网文节奏
无论何种爽感文风，下面 7 个节奏要素都重要：
1. **开篇 3 章必须爆**：废柴觉醒 -> 首次打脸 -> 收获震惊
2. **每 30 章一个小高潮**：升级 / 突破 / 大仇得报
3. **每 100 章一个大高潮**：boss 战 / 生死存亡
4. **感情线穿插**：不要集中在最后
5. **每章结尾留钩子**：让读者点下一章
6. **多视角适度切换**：不要全主角视角
7. **世界观渐进展开**：不要第一章就讲完所有设定
