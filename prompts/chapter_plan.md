# 章节大纲细化
任务：基于全书大纲中某章的粗略规划，扩写成一份 200-400 字的场景规划。
这份规划会被喂给"写章节"的模型，决定本章要写哪些动作、对话、心理、环境。
# 输入
1. 全书大纲（理解主线）。
2. 当前要细化的章节的粗规划（可能是 1-2 句话）。
3. 已写章节的状态摘要（让规划与前文衔接）。
# 输出格式
## 1. 视角人物
本章贴着谁写？不要换。
## 2. 时间地点
明确的日期、具体的小地点。
## 3. 开篇
前 50 字要进入的具体动作或物件。不要"清晨""阳光""他醒来"这种空话。
## 4. 核心动作序列
本章要发生的 3-5 个具体动作，按顺序列。每个动作一句话。
## 5. 对话
本章的关键对话（如果有）。每条对话要 5-30 字。
## 6. 暗线动作
不让叙述者明说、但要让读者隐隐感觉到的暗线动作。
## 7. 收尾
本章结尾停在哪个具体动作或物件上。不要"他望着远方"。
# 硬性要求
1. 总字数 200 到 400 字。
2. 不要写正文，只写规划。
3. 遵守 de_ai_flavour.md 规则。
4. 如果粗规划里写得不合理（例如人物 OOC、伏笔矛盾），指出来。
