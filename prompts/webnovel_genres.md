# 网文题材硬规则与爽点设定

本文件是面向网络小说市场的题材分类。
与严肃文学不同：网文以"爽感、脑洞新奇"为核心，情绪节奏快、套路明确。
模型在写网文题材时务必使用本文件的硬规则与套路，而不是传统文学标准。

# 系统流
## 硬规则
- 金手指有清晰规则与升级路径
- 系统给主角的"奖励"必须明确
- 主角必须主动使用系统（不是被动接受）
- 每次系统激活都有反馈（音效 / 弹窗 / 称号）
## 常见套路
- 装逼打脸：被看不起 -> 亮系统 -> 反派震惊
- 打怪升级：刷副本 -> 经验值 -> 升级 -> 拿装备
- 签到：每日签到 -> 累计奖励 -> 越长越丰厚
- 抽奖：开箱子 / 抽卡 -> 高级 / 垃圾
- 任务：触发任务 -> 完成 -> 奖励
- 成就：达成条件 -> 永久称号 / 永久属性
- 系统商场：用积分换宝物
## 爽点结构（黄金三章）
第 1 章：废柴被欺负 -> 觉醒金手指
第 2 章：被挑衅 -> 展示能力
第 3 章：被敬仰 / 反派求饶
## 写作时注意
- 不要"系统流过了"——必须每章都有进展
- 不要"系统不解释规则"——读者要看懂

# 无限流
## 硬规则
- 多个副本（电影 / 游戏 / 历史 / 架空）
- 每个副本有不同规则与限制
- 团队协作 + 个人抉择
- 失败 = 死亡
## 常见套路
- 任务大厅：发布任务 -> 选任务 -> 进入副本
- 抽卡选副本：进入前随机抽取
- 通关奖励：完成度 -> 评分 -> 奖励
- 复活机制：消耗资源复活队友
- 隐藏任务：某些副本有隐藏剧情
## 爽点
- 智斗：解谜破关
- 团战：与队友配合
- 绝境反杀：差点失败 -> 智取
- 收获：从副本带回宝物 / 技能
## 写作时注意
- 副本之间要"不一样"——不能换皮
- 角色死亡要"有价值"——不能白死
- 主角不能"全能"——要展现限制

# 修仙 / 玄幻（网文风）
## 硬规则
- 等级体系清晰（练气 / 筑基 / ... / 渡劫 / 仙人）
- 实力为尊——有实力就有话语权
- 主角"获得"要明确（传承 / 戒指 / 偶遇 / 重生）
- 复仇 / 打脸 / 装逼场景多
## 常见套路
- 废柴流：被看不起 -> 觉醒 -> 反杀
- 戒指老爷爷：戒指里有高手灵魂
- 重生 / 穿越：知道未来 / 携带前世记忆
- 逆袭：从最低到最高
- 扮猪吃虎：装作弱者 -> 关键时刻亮真身
- 退婚流：被退婚 -> 觉醒后让对方后悔
- 系统加点：修炼加点升级
- 师徒反目：曾信任的师父成为反派
## 爽点
- 越级反杀：境界低打赢境界高
- 获得宝物：上古传承
- 打脸装逼：装弱再亮真身
- 收获崇拜：万人敬仰
## 写作时注意
- 不要"升级太快"——要有过程
- 不要"无敌"——要有更强的对手
- 复仇要有层次——不能一刀切

# 穿越 / 重生
## 硬规则
- 主角带着"未来记忆"或"系统"
- 利用知识差碾压同时代
- 关键事件要"因主角而改变"
## 常见套路
- 历史穿越：三国 / 明朝 / 清朝 / 民初
- 都市重生：知道未来公司 / 房价 / 股票
- 平行世界：进入另一个自己的世界
- 魂穿：灵魂进入别人身体
- 回到过去：改变关键事件
## 爽点
- 知道历史大势 -> 提前布局
- 知道未来公司 -> 提前入股
- 知道房价 -> 提前买房
- 知道股票 -> 提前买入
- 改变悲剧 -> 救下亲人
## 写作时注意
- 不要"利用现代知识 + 古代"过于金手指——要有约束
- 不要"改变太多"——读者会疲劳

# 都市 / 职场（网文风）
## 硬规则
- 装逼打脸：被看不起 -> 露实力
- 神医 / 兵王 / 修仙归来 / 透视眼
- 反派都是"高富帅"——被主角打脸
## 常见套路
- 兵王归来：曾是特种兵 / 修真者 -> 退隐都市
- 透视眼：能看穿一切
- 神医：能治百病
- 修仙归来：曾是真仙 -> 重生都市
- 鉴宝：能鉴定古董真伪
## 爽点
- 打脸高富帅
- 美女投怀送抱
- 一眼看穿骗子
- 救人于危难
- 身家万贯（但装穷）
## 写作时注意
- 不要"主角全能"——给主角一些限制
- 反派不要"智商掉线"——要真的难对付
- 美女角色不要"工具化"——有自己的灵魂

# 都市异能 / 灵异
## 硬规则
- 主角有特殊能力（鬼眼 / 阴阳眼 / 通灵）
- 鬼怪有规则 / 等级
- 阴阳界有秩序
## 常见套路
- 阴阳眼：能看见鬼
- 鬼差 / 城隍：主角是阴间官员
- 风水师：能看风水 / 抓鬼
- 茅山道士：会用符咒
## 爽点
- 收服厉鬼
- 抓出幕后黑手
- 风水改命
## 写作时注意
- 不要"鬼怪太弱"——要有强敌
- 不要"迷信"——要有科学解释

# 反迪化 / 反套路
## 硬规则
- 主角"知道"原剧情（重生 / 系统）
- 故意不走原剧情
- 反向利用原剧情
## 常见套路
- 反派重生：主角成了反派
- 反派穿书：穿进自己写的反派身体
- 拆穿套路：主角能识别其他网文套路
## 爽点
- "你以为我猜不到吗？"
- "按照你们的剧本走？我偏不"
- "这个套路 100 年前就有了"
## 写作时注意
- 不要"反套路变说教"
- 不要"主角万能"——给对手一些空间

# 幕后黑手 / 观影体
## 硬规则
- 主角在暗处操作一切
- 旁观者 / 观众能看到主角操作
## 常见套路
- 漫威观影：复联众人观看另一个宇宙
- DC 观影：正义联盟观看
- 武侠观影：众人观看穿越者
## 爽点
- "他们不知道是我"
- "我已经安排好了一切"
## 写作时注意
- 不要"无脑爽"——给主角一些限制

# 通用爽点节奏
无论何种网文题材，下面 10 个节奏要素都是核心：
1. 起点困境：主角被压迫（废柴 / 退婚 / 退学 / 失业）
2. 金手指：觉醒 / 获得 / 拜师
3. 小试牛刀：第一次展现实力
4. 升级循环：每次升级都有新挑战
5. 收后宫 / 收小弟：证明主角地位
6. 长期反派：强敌压境
7. 装逼 / 震惊：每次展示都让旁观者震惊
8. 装逼升级：装逼对象从弱到强
9. 留悬念：每章结尾留钩子
10. 多线并行：多条线交织
