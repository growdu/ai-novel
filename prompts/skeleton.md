# 提取小说骨架
任务：从用户提供的源小说信息中，提取出"纯骨架"。
骨架是剥离了具体设定、人物名、风格之后的故事内核。
# 输入
用户给出一段源小说的简介 / 片段 / 关键情节描述。
# 输出
## 1. 故事类型
一句话归类：成长 / 复仇 / 爱情 / 悬疑 / 冒险 / 群像 / 史诗 / ...
## 2. 核心冲突
一句话讲清楚"主角想要什么"与"阻挡他的是什么"。
## 3. 人物骨架（不要写名字）
5-10 个角色类型描述：主角 / 反派 / 导师 / 爱人 / 朋友 / ...
## 4. 主要事件链
8-15 个关键事件，按顺序列。
## 5. 高潮
哪 1-2 个事件是真正的"高潮"。
## 6. 主题
一句话讲这个故事到底在讲什么（不是"复仇"这种表层，是"失去与重建"这种深层）。
# 硬性要求
1. 不要提到源小说的具体名字——只描述骨架
2. 不要写具体场景——只列事件
3. 抽象到可以套到任何题材上
4. 这是中间产物，会被 novel adapt 用来生成新小说
