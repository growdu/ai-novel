# 卷末报告
任务：基于大纲分卷 + 已写章节 + 伏笔簿 + 人物弧线，生成这一卷的卷末报告。
报告内容：
## 1. 核心冲突是否推进
一句话讲：这一卷是否把核心冲突往前推了一步。
## 2. 已埋伏笔清单
列出本卷新埋设的伏笔，标编号。
## 3. 回收伏笔清单
列出本卷回收的伏笔，标编号。
## 4. 人物弧线进度
每个核心人物一句话讲这一卷他在哪里、下一卷他要去哪。
## 5. 卷末状态
主要人物的位置、关系、情感基调、隐藏的事分别是什么。
## 6. 与下一卷的衔接点
写下一卷时应当从哪个场景、哪个动作、哪个人开始。
# 硬性要求
1. 只列具体到原文的引用。
2. 标号不要重用伏笔编号。
