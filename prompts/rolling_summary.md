# 滚动摘要
任务：基于最近已写章节，压缩出一份 800-1500 字的全书滚动摘要。
这份摘要与"故事状态"的区别：
- 故事状态是"上一节状态"——只看最近 3 章，喂给下一章。
- 滚动摘要是"整本书的当前状态"——让模型在写任何章节前都能拿到的全局视角。
# 摘要必须包含以下几个部分：
## 1. 当前章节进度
当前已写到第几章、属于大纲哪一卷、距离下一卷还有多少章。
## 2. 整条故事主线
用最简洁的语言概述故事到目前为止发生了什么、人物在哪里、主要冲突处于什么状态。
## 3. 人物状态摘要
每个核心人物一段：当前情感基调、最近决策、与其他人关系变化。
## 4. 世界设定增量
这一卷到现在为止，世界观里被新引入的硬规则（例如新出现的地点、新引入的物件、新确定的习俗）。
## 5. 关键伏笔追踪
最重要的 5-10 条伏笔目前的状态（已埋伏笔/已回收/被推迟）。
## 6. 写作基调备忘
这一卷到目前为止的节奏是紧张还是舒缓、语言是浓是淡、未来几章应当延续还是改变。
# 硬性要求
1. 800 到 1500 字，不要写多。
2. 直接输出，不要前言不要后缀。
3. 这份摘要会以'滚动摘要'作为标题被注入到后续章节的 prompt 里。
4. 不要照搬最近章节的句子，要做信息压缩。
