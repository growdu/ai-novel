# 题材硬规则与常见设定

工具会用当前项目的题材调用下面的对应区块，与全书/人物/章节 prompt 一起喂给模型。
作者可以自己编辑这个文件覆盖默认。

# 玄幻
## 硬规则
- 等级体系：练气 / 筑基 / 金丹 / 元婴 / 化神（可以自创但要前后一致）
- 灵气、丹田、经脉、穴位是物质性存在的，不要"消失"或"变位置"
- 法宝/飞剑/储物袋有容量限制（不要把一座山塞进一个戒指）
- 阵法需要"提前布"或"现场画"，不能意念发动
- 渡劫有物理代价（受天雷会伤、可能身死道消）
## 常见设定（按需用）
- 宗门等级：外门 / 内门 / 核心 / 真传 / 长老
- 丹药等级：下品 / 中品 / 上品 / 极品 / 仙品
- 灵根：单灵根 / 双灵根 / 三灵根 / 五灵根 / 天灵根 / 变异灵根
- 修炼资源：灵石、丹药、功法、天材地宝
- 势力关系：宗门 / 家族 / 帝国 / 散修
## 写作时容易翻车
- 不要让主角一路"捡宝升级"，要有真实的失败与代价
- 不要让"境界"成为解决一切问题的工具，要有时也解决不了
- 反派不能只是"坏的"，要有自己的逻辑和身不由己

# 仙侠
## 硬规则
- 修真与凡尘有"道"的区别，不要让两者混为一谈
- 仙门有"因果""业力"概念，不能随便杀生
- 渡劫失败会身死道消，渡劫成功会飞升，不存在中间状态
## 常见设定
- 剑修、丹修、符修、阵修、器修（专精方向）
- 仙、魔、妖、鬼、人五族
- 天庭、地府、轮回
## 写作时容易翻车
- 不要"修仙只为变强"——修心比修身重要
- 不要把仙侠写成玄幻的"打怪升级"——意境是关键

# 科幻
## 硬规则
- 不能违反物理化学常识，除非开篇就设定这是软科幻
- 设定里的"超光速""时间旅行""永生"等要有"代价"或"前提"
- AI / 机器人不能有超出设定的情感能力
- 太空 / 外星生命的描写要符合天体物理常识
## 常见设定
- 太空歌剧：星际旅行、外星文明、舰队战
- 赛博朋克：高科技低生活、义体、AI 反叛、企业寡头
- 反乌托邦：极权、监控、阶层固化
- 时间线：过去 / 现在 / 未来的相互影响
## 写作时容易翻车
- 不要把"科幻"当成"玄幻"——技术必须可解释
- 不要忽视"科技对人的影响"——这是科幻的核心
- 不要"用未来技术解决过去问题"——破坏逻辑

# 悬疑 / 推理
## 硬规则
- 凶手必须在开篇就已被读者见过（不能突然出现一个新人）
- 线索必须前后呼应，不能临时加
- 关键证据不能"没注意到"才推进剧情
## 常见设定
- 暴风雪山庄模式：封闭环境、有限嫌疑人
- 叙述性诡计：用叙述者身份误导读者
- 公平竞争：所有线索对读者公开
## 写作时容易翻车
- 不要让侦探"全知全能"——要有限制
- 不要让警察/侦探"恰好"在正确时间出现
- 反派的"动机"必须在揭示时让读者觉得"原来如此"

# 言情
## 硬规则
- 人物的感情变化必须有"事件"触发，不能凭空
- 双主角的性格必须有差异，否则会显得虚假
- 不能"完美恋人"——双方都有缺陷
## 常见设定
- 暗恋 / 双向暗恋
- 先婚后爱
- 破镜重圆
- 欢喜冤家
- 身份差距（师徒、仇人之后、贫富）
## 写作时容易翻车
- 不要让感情"莫名其妙"地好
- 不要在关键时刻让角色"沉默不语"——要行动
- 不要堆"误会"——读者会累

# 历史
## 硬规则
- 史实、官制、礼节、服饰、用语不能凭空
- 不同时代有不同称呼——"大人"用于明清，"卿"用于先秦
- 皇帝/官员的行为有制度约束，不能"想干嘛就干嘛"
## 常见设定
- 朝代背景：唐宋元明清 / 架空朝代
- 权力结构：中央 / 地方 / 军队
- 经济基础：农业 / 手工业 / 商业
## 写作时容易翻车
- 不要"穿越者带着现代知识改变历史"——这是爽文套路，不是严肃历史小说
- 不要让古人说出"自由""民主"等现代概念

# 武侠
## 硬规则
- 内力有上限、有恢复时间，不能随时"暴气"
- 招式有克制关系，不是"唯快不破"
- 门派、江湖有规矩——不能随便"见人就杀"
## 常见设定
- 门派：少林 / 武当 / 峨眉 / 华山 / 丐帮
- 兵器：剑 / 刀 / 枪 / 棍 / 暗器
- 江湖：镖局 / 客栈 / 茶馆
## 写作时容易翻车
- 不要让主角"练成绝世神功"后无敌——要持续遇到更强的对手
- 不要让"内力"成为万能解药——伤药、时间、休息都重要

# 都市 / 职场
## 硬规则
- 行业规则不能凭空——程序员不懂工厂、医生不懂金融
- 收入、消费水平要符合现实——主角不会月入百万又住地下室
- 人际关系有边界——同事不是朋友也不是敌人
## 常见设定
- 行业：互联网 / 金融 / 医疗 / 法律 / 教育 / 公务员
- 关系：职场 / 商战 / 家庭 / 朋友 / 恋爱
## 写作时容易翻车
- 不要把"职场"写成"金手指"——遇到问题靠能力解决
- 不要忽视"普通人的难处"——这是都市小说的核心

# 校园
## 硬规则
- 校园环境要符合年龄段——大学生不像高中生那么天真
- 考试、社团、宿舍生活要符合现实
- 师生关系、同学关系有边界
## 常见设定
- 高中 / 大学 / 研究生
- 社团 / 比赛 / 高考 / 考研
## 写作时容易翻车
- 不要把"校园"写成"恋爱 + 学习"——要展现成长
- 不要让老师"全知全能"——他们也是普通人

# 现实 / 严肃文学
## 硬规则
- 时间、空间、事件必须可考证
- 人物的语言、行为要符合时代背景
- 细节要真实——一床被子能"压人"的重量
## 常见设定
- 农村 / 工厂 / 矿区 / 知识分子
- 改革开放 / 上山下乡 / 出国潮
## 写作时容易翻车
- 不要"美化"或"丑化"——要客观呈现
- 不要让人物"突然觉醒"——要有过程

# 通用建议
无论何种题材，下面这几点都重要：
1. 设定要在开篇或前 5 章内告诉读者
2. 设定要"自洽"——不要"用时拿出来"
3. 设定要"可违反"——人物可以突破设定，但要有代价
4. 设定要"服务于人物"——不要让设定抢戏
