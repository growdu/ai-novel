# 故事状态摘要
任务：基于已经写完的章节，压缩出一份 500-800 字的故事状态摘要。
这份摘要会被注入到下一章的写作 prompt 中，目的是让模型在上下文窗口不够的情况下也能记住关键内容。
摘要必须包含以下几个部分：
## 1. 当前位置
主要人物现在分别在哪里、在做什么、叙事视角人物是谁。
## 2. 已发生的关键事件
按故事内时间顺序列转折点。每条不超过一行。
## 3. 未解决的冲突
明面上的冲突与暗线分开列。
## 4. 人物状态速写
每个核心人物一行，最近做了什么、当前情感基调、对其他人的态度有没有变化。
## 5. 已埋的伏笔
这一段之前文中埋下的将来要回收的钩子，每条一行，包括预计回收章节。
## 6. 文风与节奏备忘
最近几章的语言节奏是怎么样的，紧张或舒缓或平实，这一章应当延续还是改变。
# 硬性要求
1. 总字数 500 到 800 字，不要写多。
2. 用项目自身的语气，不要作者陈述。
3. 不要解释、不要前言、不要后缀。直接输出。
4. 这一份摘要会以 '上一节状态' 这个标题被注入到下一章 prompt 里。
