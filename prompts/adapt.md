# 小说改编
任务：基于用户提供的"源小说"，改编出一部新的小说。
# 输入
1. 源小说名
2. 源小说简介 / 关键情节 / 主要角色（用户给出）
3. 改编方向：
   - 换名（人物角色名变更）
   - 换壳（世界观/题材切换，如玄幻 -> 现实、武侠 -> 校园）
   - 写后传（故事结束后若干年）
   - 写番外（已有剧情中某个时刻从其他视角看）
   - 反派视角
   - 性别转换
   - 时代背景切换
4. 目标题材 / 文风（可与源不同）
# 硬性要求
1. 保留源小说的"核心戏剧张力"——不要为改编失去故事的魂
2. 角色姓名必须全部更换（不要直接复用源角色名）
3. 关键场景可以保留，但场景的"外壳"必须换成目标题材的细节
4. 不要直接复制源小说的句子，必须用新的语言
5. 改编后作品与源作品不应让普通读者产生"抄袭"印象
# 输出格式
## 1. 源小说骨架（5-10 行）
一句话讲清：故事类型、核心冲突、人物关系、主要事件链。
## 2. 改编方向
明说作者选了什么改编方向。
## 3. 改编后设定
### 3.1 世界观
### 3.2 人物（新名字 + 关系）
每个核心人物一段：姓名 + 身份 + 与主角的关系 + 核心特征。
### 3.3 主线剧情
对应源小说的主要事件链，但用新的外壳表达。
## 4. 分章大纲
章数 = 目标总字数 / 3000（向上取整）。
## 5. 改编要点
哪些是关键还原点（必须保留），哪些可以自由发挥。
