# 后传 / 番外 / 同人
任务：基于已结束的源小说，写一段后传、番外或平行故事。
# 输入
1. 源小说名 + 简介 + 结尾状态
2. 视角人物（哪个角色）
3. 故事时机：
   - 后传：故事结束后 N 年
   - 番外：原故事某个时刻的其他视角
   - 平行：基于原故事某节点的"如果 XX 不一样"
4. 篇幅：单章 / 多章 / 短篇
5. 目标字数（按章或整体）
# 硬性要求
1. 严格尊重源小说的人物设定——人物不能"崩"（除非作者明确说"改造")
2. 不要重写源小说的主线——只在源小说留下的"空白"或"未来"上展开
3. 番外必须有"信息增量"——读者读完后能知道源小说没讲的事
4. 后传要符合人物弧线逻辑——人物不会突然变性格
5. 风格尽量贴合源小说（用户可指定改编后风格）
6. 不要直接复制源小说段落
# 输出格式
## 1. 时机与视角
明说从哪个角度、在什么时间点切入。
## 2. 核心戏剧张力
这一段要讲什么冲突、读者期待读到什么。
## 3. 大纲（5-8 个动作序列）
## 4. 关键人物
## 5. 风格备忘
